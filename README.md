# TdimensionMC — Dimensional Mystery

![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS-lightgrey)
![Language](https://img.shields.io/badge/language-C%2B%2B17-blue)
![Qt](https://img.shields.io/badge/Qt-5.15%20%7C%206.x-green)
![License](https://img.shields.io/badge/license-MIT-yellow)

**Dimensional Mystery** 是一款基于 Qt 的 2D 像素风沙盒冒险游戏，以minecraft为蓝本创作。玩家在随机生成的多层世界中探索、挖掘、战斗，逐层深入击败敌人，最终挑战深层 Boss 以完成游戏。
本项目为高级语言程序设计大作业，非商业用途。

## 游戏特色

- **程序化世界生成**：168×150 方块的大世界，使用固定种子（20260419）生成正弦波地形、椭圆洞穴群、宽阔隧道，每次运行地形完全一致
- **三层深度体系**：
  - 地表层（Surface）—— 绿草、泥土、树木，僵尸与骷髅出没
  - 浅层洞穴（Shallow Cavern / Nether）—— 地狱岩、岩浆、烈焰人与僵尸猪灵
  - 深层洞穴（Deep Cavern / Forbidden）—— 最终挑战区域，雾行者 Boss 战
- **完整的物理系统**：重力、跳跃、击退、水中/岩浆中移动、蹲伏
- **五种快捷栏道具**：泥土方块、弓、剑、镐、金苹果
- **方块破坏与放置**：不同方块有不同硬度，支持挖掘进度动画
- **战斗系统**：远程弓箭射击 + 近战剑攻击（横扫/下劈），带击退与伤害冷却
- **丰富的敌人 AI**：巡逻、追击、远程射击、传送、分身、烧伤等多种行为模式
- **传送门系统**：击败一定数量敌人后激活传送门，通往更深层
- **像素风格 UI**：使用 Minecraft AE 字体，自定义像素边框样式，多层阴影标题
- **音效系统**：脚步声、受伤、弓箭命中、敌人音效等 15 种音效

## 游戏机制

### 生命值与经验

- 基础生命值 100（10 颗红心）
- 食用金苹果获得额外 50 点金色生命（5 颗金心），持续 5 秒内每秒回复 5 HP
- 击杀敌人获得经验值，积累升级
- 升级提升移动速度与挖掘速度

### 挖掘系统

| 方块类型 | 耐久值 | 推荐工具 |
|----------|--------|----------|
| 泥土 / 草方块 | 1 | 镐 / 手 |
| 石头 | 3 | 镐 |
| 树干 | 2 | 镐 |
| 树叶 | 1 | 镐 |
| 金矿 / 绿宝石矿 | 5 | 镐 |
| 红石矿 / 钻石矿 | 4 | 镐 |

- 挖掘范围内（3 格）的目标才能被挖掘
- 挖掘进度以裂纹动画显示
- 基岩层（世界底部 3 层）不可破坏

### 传送门

- **紫色传送门**（地表→浅层）：击败 25 个敌人后自动激活，落地生成紫色着陆区
- **下界传送门**（浅层→深层）：击败 5 个烈焰人 + 15 个僵尸猪灵后点亮
- **黑色传送门**：深层入口，永久激活，直达 Boss 区域

### 深度层级

| 层级 | 行范围 | 背景 | 敌人 | 特色 |
|------|--------|------|------|------|
| 地表 | 0–30 | 天空背景 | 僵尸、骷髅 | 树木、水潭、阳光 |
| 浅层洞穴 | 31–70 | 洞穴背景 | 烈焰人、僵尸猪灵 | 地狱岩、岩浆、岩浆块 |
| 深层洞穴 | 71–150 | 深层洞穴背景 | 雾行者 | 紫光、恐惧 debuff、Boss 战 |

## 敌人图鉴

### 僵尸（Zombie）
- 生命值：100
- 伤害：2
- 行为：向玩家移动，近战攻击
- 出没：地表层

### 骷髅（Skeleton）
- 生命值：100
- 伤害：2（远程弓箭）
- 行为：与玩家保持距离，远程射击
- 出没：地表层

### 烈焰人（Blaze）
- 生命值：60
- 伤害：2（火球，附带 3 秒燃烧）
- 行为：悬浮移动，蓄力发射火球，保持最佳距离 12 格
- 特性：被击中后短暂闪现红色
- 出没：浅层洞穴（下界）

### 僵尸猪灵（Zombified Piglin）
- 生命值：20
- 伤害：2
- 行为：中立巡逻，受到攻击后激怒周围同伴
- 出没：浅层洞穴（下界）

### 雾行者（Fog Stalker）— 深层 Boss
- 生命值：300
- 行为：
  - **多阶段战斗**：攻击模式随血量变化
  - **传送**：随机传送到玩家周围安全位置
  - **分身**：生成幻影克隆迷惑玩家
  - **恐惧 Debuff**：叠加降低玩家视野
  - **闪电闪现**：传送时伴随视觉效果
  - **击晕**：特定攻击可短暂击晕
- 出没：深层洞穴（Forbidden）

## 构建与运行

### 环境要求

- **CMake** ≥ 3.16
- **C++17** 编译器（MSVC 2019+ / MinGW 8.0+ / GCC 8+ / Clang 8+）
- **Qt** 5.15 或 6.x（需要 Widgets 和 Multimedia 模块）

### 构建步骤

```bash
# 克隆仓库
git clone https://github.com/your-username/TdimensionMC.git
cd TdimensionMC

# 创建构建目录
mkdir build && cd build

# 配置（Qt6）
cmake .. -DCMAKE_PREFIX_PATH=/path/to/Qt/6.x.x/gcc_64

# 配置（Qt5）
cmake .. -DCMAKE_PREFIX_PATH=/path/to/Qt/5.15.2/gcc_64

# 编译
cmake --build . --config Release
```

### 资源文件

游戏运行时从以下两个路径（按优先级）加载资源：

1. 可执行文件所在目录的 `assets/` 文件夹
2. 编译时指定的默认路径（`D:/develop/Qtproject/TdimensionMC/assets`）

运行前请确保 `assets/` 目录包含：

```

    ├── yanjiangkuai.png  # 岩浆块
```

## 项目结构

```
TdimensionMC/
├── CMakeLists.txt              # CMake 构建配置
├── main.cpp                    # 程序入口
├── mainwindow.h / .cpp / .ui   # 主窗口（菜单、帮助、界面切换）
├── gamewidget.h / .cpp         # 游戏核心（物理、渲染、世界、AI）
├── dirtblock.h / .cpp          # 土地方块类（7 种类型）
├── treeblock.h / .cpp          # 树木方块类（树干/树叶）
├── oreblock.h / .cpp           # 矿石方块类（4 种矿石）
├── resources.qrc               # Qt 资源文件
├── assets/
│   └── blocks/                 # 方块纹理图片
├── soundeffect/                # 游戏音效（MP3）
└── tools/
    └── build_live_windows.py   # 辅助构建脚本
```

### 核心类说明

| 类 | 职责 |
|----|------|
| `MainWindow` | 管理开始菜单、帮助界面、游戏界面的切换，键盘快捷操作 |
| `GameWidget` | 游戏主循环、世界生成、物理模拟、敌人 AI、渲染、HUD |
| `DirtBlock` | 可挖掘的地形方块（泥土/石头/草/地狱岩/岩浆块/石英/黑色） |
| `TreeBlock` | 可挖掘的树木方块（树干/树叶） |
| `OreBlock` | 可挖掘的矿石方块（金/绿宝石/红石/钻石） |

`GameWidget` 是整个项目的核心，约 5900 行，包含：
- 世界生成（`initializeWorld`）— 地形、洞穴、隧道、传送门
- 物理引擎（重力、碰撞检测、液体物理）
- 敌人 AI（巡逻、追击、射击、传送、Boss 阶段切换）
- 战斗系统（弓箭弹道、剑攻击判定、伤害计算、击退）
- 渲染系统（方块、玩家、敌人、投射物、HUD、粒子特效）
- 深度层级管理（传送门、层级切换、提示系统）

## 技术细节

- **固定世界种子**：`20260419`，保证每次生成地形完全一致
- **渲染方式**：纯 `QPainter` 软件渲染，像素对齐无抗锯齿
- **碰撞检测**：基于方块网格的 AABB 碰撞，分水平和垂直两个通道独立处理
- **敌人 AI**：每种敌人有独立的巡逻、追击、攻击状态机
- **音效管理**：使用 `QMediaPlayer`，区分怪物音效和地表怪物音效两组独立管理
- **跨 Qt 版本**：同时兼容 Qt 5.15 和 Qt 6.x，通过 `QT_VERSION` 宏处理 API 差异
